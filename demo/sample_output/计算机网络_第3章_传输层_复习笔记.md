## 核心定义（8 条）

- ★ 传输层是指为两台主机中的应用进程提供端到端通信服务的层次。（P2）
- ★ 端到端通信是指数据从发送方进程直接送到接收方进程，中间网络不拆开看。（P2）
- ★ 端口是指传输层用来标识应用进程的 16 位编号。（P3）
- 套接字是指 IP 地址与端口号的组合。（P3）
- UDP 是一种无连接的传输层协议。（P4）
- TCP 是一种面向连接的、提供可靠交付的传输层协议。（P5）
- ★ 拥塞控制是指防止过多数据注入网络、导致网络性能下降的机制。（P7）
- ☆ 了解内容：TCP 选项字段的扩展用法属于选学，考试一般不考。（P8）

## 公式（2 条）

- 吞吐量 = 窗口大小 / 往返时间 RTT（P6）
- 信道利用率 U = 吞吐量 / 带宽（P6）

## 结论（12 条）

- ★ 本章重点：端口、UDP、TCP、拥塞控制。（P2）
- 端口号范围是 0 ~ 65535。（P3）
- UDP 的特点是开销小、时延低，但不保证可靠交付。（P4）
- 因此 UDP 适合实时音视频这类能容忍少量丢包的场景。（P4）
- TCP 通过序号、确认、重传三项机制实现可靠传输。（P5）
- TCP 建立连接需要三次握手，释放连接需要四次挥手。（P5）
- 结论：窗口越大吞吐量越高，但受网络拥塞限制。（P6）
- 慢开始阶段，拥塞窗口从 1 开始按指数增长。（P7）
- 到达慢开始门限后进入拥塞避免，改为线性增长。（P7）
- 结论：因此拥塞控制是站在网络整体角度考虑问题。（P7）
- ★ 传输层的核心是端到端通信、端口寻址与可靠传输。（P10）
- ★ 重点掌握：端到端通信、端口、UDP、TCP、拥塞控制。（P10）

## 易错点（4 条）

- 注意区分：端口标识进程，IP 地址标识主机。（P3）
- 常见错误：把 UDP 当成可靠传输协议，这是典型易错点。（P4）
- 易错点：流量控制是端到端的，拥塞控制面向整个网络，两者不要混淆。（P8）
- 注意区分：流量控制靠接收窗口，拥塞控制靠拥塞窗口。（P8）
